【项目概述】

老年极简购物助手 是一款专为老年人设计的极简风格在线购物 Web 应用。项目采用
"大字体、暖色调、简操作"的设计理念，降低老年人使用数字购物的门槛，同时引入
"亲情代付"机制，让子女可以远程为父母订单付款，体现科技温度。

--------------------------------------------------------------------------------

【技术栈】

  前端：       原生 HTML + CSS + JavaScript（单页应用 SPA）
  后端：       Node.js + Express.js
  数据存储：   JSON 文件（轻量级，无需数据库）
  AI 集成：    DeepSeek API（通过 axios 调用）
  环境配置：   dotenv
  跨域支持：   cors

  依赖包：
    - express  ^5.2.1    Web 框架
    - cors     ^2.8.6    跨域资源共享
    - axios             HTTP 客户端（用于调用 AI API）
    - dotenv            环境变量管理

【功能模块】

1. 用户认证系统
   - 注册：手机号 + 密码 + 称呼 + 身份（老年人/子女）
   - 登录：手机号 + 密码验证
   - 退出登录：清除本地会话
   - 角色区分：老年人账号进入购物首页，子女账号进入代付页面

2. 商品浏览
   - 三大分类：食品饮料、日用品、药品保健
   - 随便看看：展示所有商品
   - Emoji 图文匹配：每件商品配有对应 Emoji 图标，直观易懂
   - 商品详情：名称、描述、价格清晰展示
   - 老年友好标记：部分商品标注为老年适用产品

3. 智能搜索
   - 支持模糊匹配（商品名称、描述、分类、标签）
   - 支持多关键词搜索（空格分隔）
   - 搜索历史自动记录，用于个性化推荐

4. 智能推荐系统
   采用混合推荐算法，包含以下维度：
     - 品类偏好（35%）：基于用户浏览历史和搜索关键词推断偏好品类
     - 关键词匹配（25%）：搜索词与商品信息的文本匹配度
     - 协同过滤（20%）：基于全局热门商品（购物车+订单统计）
     - 老年适用（20%）：优先推荐老年友好型商品
   冷启动策略：新用户无行为数据时，推荐老年用品 + 全局热门商品。

5. 购物车管理
   - 添加商品到购物车
   - 删除购物车商品
   - 实时计算合计金额
   - 购物车商品在推荐时自动排除（避免重复推荐）

6. 亲情代付（订单系统）
   老年人流程：
     1. 选好物品的加入购物车
     2. 点击"去结算（亲情代付）"
     3. 系统创建待付订单，等待子女付款

   子女流程：
     1. 以"子女"身份登录
     2. 查看待代付订单列表
     3. 点击"帮我代付"完成付款
     4. 订单状态更新为"已代付"

   订单状态流转：pending（待代付） -> paid（已代付） -> completed（已完成）

7. AI 导购助手
   集成 DeepSeek AI 大语言模型，为购物车商品生成个性化购买建议：
   - 对商品选择进行总体肯定
   - 提供 2-3 个实用搭配建议
   - 语气亲切温暖，适合老年用户
   - 建议内容不超过 200 字

8. 用户行为追踪
   自动记录以下行为数据，驱动推荐算法：
   - 搜索行为：关键词、时间（保留最近 50 条）
   - 浏览行为：商品ID、品类、时间（保留最近 100 条）
   - 浏览次数：各商品被查看次数（无上限）

【API 接口】

  用户相关：
    POST   /api/users              用户注册
    POST   /api/login              用户登录

  商品相关：
    GET    /api/goods              获取所有商品
    GET    /api/goods/:category    按分类获取商品
    GET    /api/search?q=关键词    搜索商品

  购物车：
    GET    /api/cart/:userId              获取用户购物车
    POST   /api/cart/:userId/items        添加商品到购物车
    DELETE /api/cart/:userId/items/:itemId 删除购物车商品

  订单：
    POST   /api/orders              创建订单
    GET    /api/orders/:userId      获取用户订单
    GET    /api/orders/pending      获取待代付订单
    POST   /api/orders/:orderId/pay 支付订单（子女代付）

  行为追踪：
    POST   /api/behavior/search     记录搜索行为
    POST   /api/behavior/browse     记录浏览行为

  推荐与 AI：
    GET    /api/recommendations/:userId  获取个性化推荐
    POST   /api/ai-advice              获取 AI 购物建议

【如何运行】

  环境要求：Node.js >= 16

  1. 安装依赖
     npm install

  2. 配置 AI（可选）
     在 .env 文件中填入你的 DeepSeek API Key：
     DEEPSEEK_API_KEY=your-api-key-here
     如不配置，AI 导购助手功能将不可用，其余功能正常运行。

  3. 启动服务器
     npm start

  4. 访问应用
     浏览器打开 http://localhost:3000 即可使用。
