# Companion Cart — AI 协同购物助手

> 面向老年人与视障用户的 AI 协同购物 Web 应用。老人只需说话即可购物，AI 朗读商品与风险，家人远程确认付款。

**项目原名**：SeniorShop（老年极简购物助手）  
**课程**：人机交互（HCI）课程最终项目  
**仓库**：https://github.com/MonicaJiangInCollege/hci-SeniorShop

---

## 一、项目概述

**Companion Cart** 是一款专为老年人和视障/低视力用户设计的极简购物 Web 应用。项目以"说话优先（Voice First）"和"看不清也能买（Accessible By Default）"为核心设计理念，通过以下方式降低数字购物门槛：

- **AI 协同购物**：集成 DeepSeek 大语言模型，提供智能导购、意图识别、自动加购
- **语音交互**：百度语音 SDK + 浏览器 Web Speech API，支持语音输入、语音播报、语音唤起
- **低视力/盲人模式**：黑底黄字、超大字号、单卡片展示、逐条朗读
- **纯语音购物模式**：全程语音操作，无需触屏
- **家庭守护台**：子女远程查看订单来源、风险说明，确认后帮付
- **智能安全提醒**：自动检测药品、保健品、大额消费，保护老年人购物安全
- **无障碍确认弹窗**：替换原生 `confirm()`，支持焦点管理 + 屏幕阅读器朗读

## 四、设计原则

Companion Cart 遵循六条核心设计原则：

| 原则 | 说明 |
|------|------|
| **1. 说话优先（Voice First）** | 首页第一行动是"说话购物：开启小伴"，低视力模式支持语音命令 |
| **2. 看不清也能买（Accessible By Default）** | 高对比黑底、超大字号、粗边框、单卡片商品展示 |
| **3. 少而明确（Low Cognitive Load）** | 仅四个入口（食品饮料、日用品、药品保健、随便看看），固定四步任务状态 |
| **4. AI 有职责（Accountable AI）** | AI 负责理解需求、筛选商品、朗读解释，不绕过安全确认 |
| **5. 家庭共同确认（Family CSCW）** | 子女端是"家庭守护台"，看到订单来源、风险原因后确认付款 |
| **6. 风险可解释（Trustworthy UX）** | 药品、保健品、大额订单触发风险解释，所有结算统一走安全链路 |

## 五、功能模块

### 5.1 用户认证系统

| 功能 | 说明 |
|------|------|
| 身份选择 | 启动时选择"老人"或"子女"身份入口 |
| 注册 | 手机号 + 密码 + 称呼；子女注册需填写父母手机号以建立绑定关系 |
| 登录 | 手机号 + 密码验证 |
| 退出登录 | 清除本地会话 |
| 角色区分 | 老年人账号进入购物首页，子女账号进入家庭守护台 |
| 亲子绑定 | 子女注册时通过父母手机号自动绑定，只能查看已绑定老人的订单 |

### 5.2 无障碍功能（Accessibility）

#### 低视力/盲人模式

- **黑底黄字**：高对比度配色方案
- **超大字号**：34px 商品名、36px 价格
- **单卡片展示**：一次只展示一个商品，减少认知负担
- **逐条朗读**：自动朗读当前商品名称、价格、描述
- **语音命令**：支持"下一个"、"上一个"、"读一遍"、"放进清单"、"让孩子看看"
- **大按钮操作**：64px 最小高度，14px 圆角

#### 纯语音购物模式

- 全程语音操作，无需触屏
- 语音导航：打开分类、搜索、加购、结算
- 语音反馈：每步操作都有语音播报
- 语音确认结算：需明确说"确认提交"才下单

#### ARIA 无障碍

- **ARIA Live Region**：屏幕阅读器可见的隐藏区域，页面切换时自动广播
- **焦点管理**：页面切换后自动将焦点移到页面标题
- **语义化标签**：`aria-label`、`role="navigation"`、`aria-live="polite"`
- **说话时自动停止 TTS**：用户开始说话时立即停止正在播报的语音

#### 无障碍确认弹窗

- 替换原生 `confirm()` 对话框，使用自定义无障碍弹窗
- 支持焦点管理：弹窗打开时焦点移到确认按钮，关闭时恢复焦点到触发元素
- 屏幕阅读器朗读：弹窗打开时自动朗读标题和内容
- 点击遮罩关闭：视为取消操作

### 5.3 商品浏览

- **四大入口**：食品饮料、日用品、药品保健、随便看看
- **子分类筛选**：每个主分类下设多个子分类
- **随便看看**：展示所有商品 + 智能推荐区
- **Emoji 图文匹配**：每件商品配有对应 Emoji 图标
- **商品详情页**：大图 Emoji、名称、价格、详细描述、标签、老年适用标记

#### 子分类结构

| 主分类 | 子分类 |
|--------|--------|
| 食品饮料 | 饮品、主食、零食干货、调味品 |
| 日用品 | 纸品家清、个人护理、厨房用品、老年辅具 |
| 药品保健 | 保健滋补、医疗器械、防护卫生、外用护理 |

### 5.4 智能找找

- 支持模糊匹配（商品名称、描述、分类、标签）
- 支持多关键词搜索（空格分隔，全部匹配才返回）
- 搜索历史自动记录，用于个性化推荐

### 5.5 智能推荐系统

采用**混合推荐算法**：

| 维度 | 权重 | 说明 |
|------|------|------|
| 品类偏好 | 35% | 基于用户浏览历史和搜索关键词推断偏好品类 |
| 关键词匹配 | 25% | 搜索词与商品信息的文本匹配度 |
| 协同过滤 | 20% | 基于全局热门商品（购物车+订单统计） |
| 老年适用 | 20% | 优先推荐老年友好型商品 |

**冷启动策略**：新用户无行为数据时，推荐老年用品 + 全局热门商品。

### 5.6 购物车管理

- 添加商品到购物车（从商品列表、详情页、推荐区、AI 对话均可）
- 删除购物车商品
- 实时计算合计金额
- AI 导购助手分析购物车内容并提供购买建议

### 5.7 家庭守护台（亲情帮付）

**老年人流程**：
1. 选好商品加入购物车
2. 点击"超大确认：提交给家人付款"或语音说"去结算"
3. 系统创建待付订单，等待子女付款
4. 在"我买的东西"中查看订单状态

**子女流程**：
1. 以"子女"身份登录
2. 进入"家庭守护台"
3. 查看"今日待确认"或"已帮家人付好"订单
4. 查看订单来源（语音/AI/点击）、辅助模式、风险解释
5. 点击"确认无误，帮家人付"完成付款
6. 或点击"先退回，让家人再确认"

**订单状态流转**：`pending（等确认）` → `paid（已付好）`

### 5.8 AI 智能导购助手

集成 **DeepSeek AI** 大语言模型，提供全场景智能购物辅助。

#### 5.8.1 全场景浮动按钮

- 在所有购物页面右下角显示 AI 浮动按钮（🤖）
- 点击打开 AI 聊天弹窗
- 支持对话历史（多轮对话）

#### 5.8.2 聊天功能

| 功能 | 说明 |
|------|------|
| 文字对话 | 输入框 + 发送按钮，支持 Enter 快捷发送 |
| 语音输入 | 麦克风按钮，录音后自动识别为文字并发送 |
| 语音播报 | 每条 AI 回复旁有朗读按钮 |
| 快捷问题 | 预设 4 个快捷问题按钮 |
| 商品点击链接 | AI 回复中的商品名以可点击按钮展示 |
| 对话历史 | 完整保留上下文，支持多轮连续对话 |
| 固定欢迎语 | 首次打开时显示固定欢迎词，自动语音播报 |

#### 5.8.3 意图识别与自动执行

| 意图类型 | 示例 | 执行动作 |
|----------|------|----------|
| 加入购物车 | "我要买纯牛奶" | 自动将匹配商品加入购物车 |
| 结算 | "去结算"、"帮我付款" | 提示确认订单 |
| 导航 | "看看食品饮料"、"去购物车" | 自动跳转到对应页面 |

#### 5.8.4 购物车购买建议

在购物车页面，点击"获取购买建议"按钮，AI 分析购物车内容并提供搭配建议。

#### 5.8.5 子女联动通知

当检测到药品购买或大额消费（>¥100）时，自动显示通知横幅。

### 5.9 语音交互

集成 **百度 AI 语音 SDK** + **浏览器 Web Speech API**：

| 功能 | 技术 | 说明 |
|------|------|------|
| 语音识别 (ASR) | 百度 AI SDK | 录音转文字，支持中文普通话远场识别 |
| 语音合成 (TTS) | 百度 AI SDK（降级浏览器 TTS） | 文字转语音，AI 回复可一键朗读 |
| 语音唤起 | 浏览器 Web Speech API | 后台持续监听"你好小伴"唤醒词 |
| 语音命令 | 浏览器 Web Speech API | 唤醒后可直接语音执行导航、加购、搜索、结算 |

**语音唤起功能**：
- 唤醒词："你好小伴"、"嗨小伴"、"小伴"
- 后台持续监听，检测到唤醒词后自动打开 AI 聊天窗口
- 麦克风指示器：右上角显示监听状态（呼吸动画）
- 语音命令执行提示：顶部 toast 显示正在执行的命令

**语音命令示例**：

| 语音指令 | 执行动作 |
|----------|----------|
| "看看食品饮料" | 打开食品饮料分类 |
| "看看日用品" | 打开日用品分类 |
| "看看药品保健" | 打开药品保健分类 |
| "随便看看" | 打开随便看看页面 |
| "看看购物车" | 打开购物车 |
| "看看我买的东西" | 打开我的订单 |
| "返回首页" | 返回购物首页 |
| "我要买纯牛奶" | 搜索并加入购物车 |
| "找找降压药" | 搜索并显示结果 |
| "去结算" | 提交订单 |
| "再见" | 关闭 AI 聊天窗口 |

### 5.10 智能安全提醒

提交订单时自动检测：
- **药品检测**：识别药品保健类商品（medicine 分类）
- **大额检测**：订单金额超过 ¥100 时触发提醒
- 触发提醒后显示安全提示，确认后才提交订单
- 子女端订单卡片会标注"含药品"或"大额"标记

## 七、API 接口

### 用户相关

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/api/users` | 用户注册（支持亲子绑定） |
| POST | `/api/login` | 用户登录 |

### 商品相关

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/goods` | 获取所有商品 |
| GET | `/api/goods/:category` | 按分类获取商品 |
| GET | `/api/search?q=关键词` | 搜索商品 |

### 购物车

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/cart/:userId` | 获取用户购物车 |
| POST | `/api/cart/:userId/items` | 添加商品到购物车 |
| DELETE | `/api/cart/:userId/items/:itemId` | 删除购物车商品 |

### 订单

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/api/orders` | 创建订单（含智能安全提醒） |
| GET | `/api/orders/:userId` | 获取用户订单 |
| GET | `/api/orders/pending?childUserId=` | 获取待付订单（按绑定关系过滤） |
| GET | `/api/orders/paid-by-child?childUserId=` | 子女查看已付订单 |
| POST | `/api/orders/:orderId/pay` | 支付订单（子女帮付） |

### 行为追踪

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/api/behavior/search` | 记录搜索行为 |
| POST | `/api/behavior/browse` | 记录浏览行为 |

### 推荐与 AI

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/recommendations/:userId` | 获取个性化推荐 |
| POST | `/api/ai-advice` | 获取 AI 购物建议（支持全场景对话 + 意图识别） |

### 语音服务

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/api/speech/asr` | 语音识别（音频 base64 → 文字） |

## 八、如何运行

### 环境要求

- Node.js >= 16

### 安装依赖

```bash
npm install
```

### 配置 AI 和语音服务（可选）

在 `.env` 文件中填入你的 API 密钥：

```env
# DeepSeek AI（用于智能导购助手）
DEEPSEEK_API_KEY=your-deepseek-api-key-here

# 百度语音（用于语音识别 + 语音合成）
BAIDU_SPEECH_APP_ID=your-app-id
BAIDU_SPEECH_API_KEY=your-api-key
BAIDU_SPEECH_SECRET_KEY=your-secret-key
```

> - 如不配置 DeepSeek API Key，AI 导购助手功能将不可用，其余功能正常运行。
> - 如不配置百度语音，语音输入和语音播报功能将不可用，其余功能正常运行。
> - 语音唤起功能使用浏览器 Web Speech API，无需额外配置（Chrome/Edge 支持最佳）。

## 九、测试账号流程

### 老年人购物流程

1. 选择"我是老人"身份 → 注册账号 → 登录
2. 浏览商品分类 / 找找商品 / 随便看看
3. 点击商品查看详情
4. 将商品加入购物车
5. 与 AI 助手对话获取购物建议（文字或语音）
6. 说"你好小伴"语音唤起 AI 助手
7. 点击"超大确认"创建待付订单
8. 在"我买的东西"中查看订单状态

### 无障碍购物流程

1. 以老人身份登录后，进入低视力模式
2. 系统自动朗读当前商品，支持"下一个"、"读一遍"、"放进清单"
3. 选好后说"让孩子看看"，进入结算确认
4. 说"确认提交"完成下单

### 纯语音购物流程

1. 以老人身份登录后，开启语音模式
2. 全程语音操作："我要买纯牛奶"、"看看购物车"、"去结算"
3. 结算时需明确说"确认提交"才下单

### 子女帮付流程

1. 选择"我是子女"身份 → 注册账号（需填写父母手机号）→ 登录
2. 进入"家庭守护台"
3. 查看"今日待确认"订单列表，查看订单来源、风险解释
4. 点击"确认无误，帮家人付"完成付款
5. 在"已帮家人付好"标签页查看历史帮付记录

### AI 助手使用示例

| 用户输入 | AI 响应 |
|----------|---------|
| "帮我推荐适合老人的食品" | 推荐高钙牛奶、红枣等老年友好商品 |
| "有没有降血压的药？" | 从商品目录中精确匹配回答 |

| "去购物车" | 自动跳转到购物车页面 |
| 语音输入 | 自动识别为文字并处理 |

### 语音唤起使用示例

| 语音指令 | 执行动作 |

| "你好小伴，看看购物车" | 打开购物车页面 |

## 十、项目亮点

1. **极简适老设计**：大字体、大按钮、暖色调、语义化中文文案
2. **低视力/盲人模式**：黑底黄字、超大字号、单卡片展示、逐条朗读
3. **纯语音购物**：全程语音操作，无需触屏
4. **语音唤起**：后台持续监听"你好小伴"唤醒词
5. **ARIA 无障碍**：屏幕阅读器支持、焦点管理、语义化标签
6. **无障碍确认弹窗**：替换原生 confirm，支持焦点管理 + 屏幕阅读器朗读
7. **说话时自动停止 TTS**：避免语音播报与用户说话冲突
8. **通俗化文案**：全站使用老年人易懂的语言
9. **Emoji 图文匹配**：用 Emoji 替代复杂图片，直观易懂
10. **智能推荐系统**：混合推荐算法，冷启动 + 个性化双模式
11. **家庭守护台**：创新性家庭协作购物模式
12. **AI 智能导购**：集成 DeepSeek 大模型，意图识别、自动执行
13. **语音交互**：百度语音 SDK + 浏览器 Web Speech API
14. **智能安全提醒**：自动检测药品和大额消费
15. **行为追踪学习**：自动学习用户偏好
16. **轻量部署**：JSON 文件存储，无需数据库

## 十一、已知限制与改进方向

| 限制 | 说明 | 改进方向 |
|------|------|----------|
| 密码明文存储 | 未进行加密处理 | 引入 bcrypt 加密 |
| 无身份验证机制 | 无 Session/Token | 实现 JWT Token 验证 |
| JSON 文件存储 | 不适合生产环境 | 引入 SQLite / MongoDB |
| 无前端单元测试 | 缺乏自动化测试 | 引入 Jest / Vitest |
| 无地址管理 | 订单无收货地址 | 增加地址管理模块 |
| 语音唤起兼容性 | Safari 不支持 Web Speech API | 已做降级处理，提示用户点击按钮 |
