# 老年极简购物助手 (SeniorShop)

## 项目概述

**老年极简购物助手** 是一款专为老年人设计的极简风格在线购物 Web 应用。项目采用"大字体、暖色调、简操作"的设计理念，降低老年人使用数字购物的门槛，同时引入"亲情帮付"机制，让子女可以远程为父母订单付款，体现科技温度。

应用集成 **AI 智能导购助手**（基于 DeepSeek 大语言模型）和 **语音交互**（基于百度语音 SDK + 浏览器 Web Speech API），支持文字对话、语音输入、语音播报、语音唤起、意图识别与自动执行，为老年用户提供全方位的智能购物辅助。

## 技术栈

| 层级 | 技术 |
|------|------|
| 前端 | 原生 HTML + CSS + JavaScript（单页应用 SPA） |

## 功能模块

### 1. 用户认证系统

| 功能 | 说明 |
|------|------|
| 身份选择 | 启动时选择"老人"或"子女"身份入口 |
| 注册 | 手机号 + 密码 + 称呼；子女注册需填写父母手机号以建立绑定关系 |
| 登录 | 手机号 + 密码验证 |
| 退出登录 | 清除本地会话 |
| 角色区分 | 老年人账号进入购物首页，子女账号进入帮付中心 |
| 亲子绑定 | 子女注册时通过父母手机号自动绑定，只能查看已绑定老人的订单 |

### 2. 商品浏览

- **三大主分类**：食品饮料、日用品、药品保健
- **子分类筛选**：每个主分类下设多个子分类（如饮品/主食/零食干货/调味品等）
- **随便看看**：展示所有商品 + 智能推荐区
- **Emoji 图文匹配**：每件商品配有对应 Emoji 图标，直观易懂
- **商品详情页**：包含大图 Emoji、名称、价格、详细描述、标签、老年适用标记
- **老年友好标记**：部分商品标注为老年适用产品（⭐）

#### 子分类结构

| 主分类 | 子分类 |
|--------|--------|
| 食品饮料 | 饮品、主食、零食干货、调味品 |
| 日用品 | 纸品家清、个人护理、厨房用品、老年辅具 |
| 药品保健 | 保健滋补、医疗器械、防护卫生、外用护理 |

### 3. 智能找找

- 支持模糊匹配（商品名称、描述、分类、标签）
- 支持多关键词搜索（空格分隔，全部匹配才返回）
- 搜索历史自动记录，用于个性化推荐
- 搜索结果数量提示

### 4. 智能推荐系统

采用**混合推荐算法**，包含以下维度：

| 维度 | 权重 | 说明 |
|------|------|------|
| 品类偏好 | 35% | 基于用户浏览历史和搜索关键词推断偏好品类 |
| 关键词匹配 | 25% | 搜索词与商品信息的文本匹配度 |
| 协同过滤 | 20% | 基于全局热门商品（购物车+订单统计） |
| 老年适用 | 20% | 优先推荐老年友好型商品 |

**冷启动策略**：新用户无行为数据时，推荐老年用品 + 全局热门商品。

**推荐展示位置**："随便看看"页面的"猜您喜欢"专区。

### 5. 购物车管理

- 添加商品到购物车（从商品列表、详情页、推荐区、AI 对话均可）
- 删除购物车商品
- 实时计算合计金额
- 购物车商品在推荐时自动排除（避免重复推荐）
- AI 导购助手分析购物车内容并提供购买建议

### 6. 亲情帮付（订单系统）

**老年人流程**：
1. 选好商品加入购物车
2. 点击"去付钱（让子女帮忙付）"
3. 系统创建待付订单，等待子女付款
4. 在"我买的东西"中查看订单状态

**子女流程**：
1. 以"子女"身份登录
2. 进入"帮付中心"
3. 查看"等着我付"或"已付过的"订单列表
4. 点击"帮我付"完成付款
5. 订单状态更新为"已付过"

**订单状态流转**：`pending（等着我付）` → `paid（已付过）` → `completed（已完成）`

### 7. AI 智能导购助手

集成 **DeepSeek AI** 大语言模型，提供全场景智能购物辅助。

#### 7.1 全场景浮动按钮

- 在所有购物页面右下角显示 AI 浮动按钮（🤖）
- 点击打开 AI 聊天弹窗
- 支持对话历史（多轮对话）

#### 7.2 聊天功能

| 功能 | 说明 |
|------|------|
| 文字对话 | 输入框 + 发送按钮，支持 Enter 快捷发送 |
| 语音输入 | 麦克风按钮，录音后自动识别为文字并发送 |
| 语音播报 | 每条 AI 回复旁有朗读按钮，点击即可语音播报回复内容 |
| 快捷问题 | 预设 4 个快捷问题按钮，一键提问 |
| 商品点击链接 | AI 回复中的商品名以可点击按钮展示，点击跳转商品详情 |
| 对话历史 | 完整保留上下文，支持多轮连续对话 |
| 固定欢迎语 | 首次打开 AI 助手时显示固定欢迎词，自动语音播报 |

#### 7.3 意图识别与自动执行

AI 助手能识别用户意图并自动执行操作：

| 意图类型 | 示例 | 执行动作 |
|----------|------|----------|
| 加入购物车 | "我要买纯牛奶"、"帮我加面包到购物车" | 自动将匹配商品加入购物车 |
| 结算 | "去结算"、"帮我付款" | 提示确认订单 |
| 导航 | "看看食品饮料"、"去购物车" | 自动跳转到对应页面 |

#### 7.4 购物车购买建议

在购物车页面，点击"获取购买建议"按钮：
- 对商品选择进行总体肯定
- 提供 2-3 个实用搭配建议
- 检查是否有重复或不需要购买的商品
- 语气亲切温暖，适合老年用户
- 建议内容不超过 200 字

#### 7.5 子女联动通知

当检测到药品购买或大额消费（>¥100）时，自动显示通知横幅提醒已通知子女关注。

### 8. 语音交互

集成 **百度 AI 语音 SDK** + **浏览器 Web Speech API**，提供完整的语音交互能力：

| 功能 | 技术 | 说明 |
|------|------|------|
| 语音识别 (ASR) | 百度 AI SDK | 将录音（base64）转换为文字，支持中文普通话远场识别 |
| 语音合成 (TTS) | 百度 AI SDK（降级浏览器 TTS） | 将文字转换为语音音频，AI 回复可一键朗读 |
| 语音唤起 | 浏览器 Web Speech API | 后台持续监听"你好小伴"唤醒词，无需点击即可打开 AI 助手 |
| 语音命令 | 浏览器 Web Speech API | 唤醒后可直接语音执行导航、加购、搜索、结算等操作 |

**语音唤起功能**：
- 唤醒词："你好小伴"、"嗨小伴"、"小伴"
- 后台持续监听，检测到唤醒词后自动打开 AI 聊天窗口
- 唤醒后可直接说后续指令，如"你好小伴，帮我看看牛奶多少钱"
- 麦克风指示器：右上角显示监听状态（呼吸动画）
- 语音命令执行提示：顶部 toast 显示正在执行的命令

**语音命令示例**：
| 语音指令 | 执行动作 |
|----------|----------|
| "看看食品饮料" | 打开食品饮料分类 |
| "看看日用品" | 打开日用品分类 |
| "看看药品保健" | 打开药品保健分类 |
| "随便看看" | 打开随便看看页面 |
| "看看购物车" | 打开购物车 |
| "看看我买的东西" | 打开我的订单 |
| "返回首页" | 返回购物首页 |
| "我要买纯牛奶" | 搜索并加入购物车 |
| "找找降压药" | 搜索并显示结果 |
| "去结算" | 提交订单 |
| "再见" | 关闭 AI 聊天窗口 |

**使用场景**：
- AI 聊天中输入框旁的麦克风按钮 → 录音 → 自动识别为文字
- AI 回复气泡旁的朗读按钮 → 点击 → 语音播报回复内容
- 后台语音唤起 → 说"你好小伴" → 自动打开 AI 助手

### 9. 智能安全提醒

提交订单时自动检测：
- **药品检测**：识别维生素、钙片、鱼油、体温计、口罩等药品保健类商品
- **大额检测**：订单金额超过 ¥100 时触发提醒
- 触发提醒后显示安全提示，确认后才提交订单
- 子女端订单卡片会标注"含药品"或"大额"标记

### 10. 用户行为追踪

自动记录以下行为数据，驱动推荐算法：

| 行为类型 | 记录内容 | 保留上限 |
|----------|----------|----------|
| 搜索行为 | 关键词、时间 | 最近 50 条 |
| 浏览行为 | 商品ID、品类、时间 | 最近 100 条 |
| 浏览次数 | 各商品被查看次数 | 无上限 |

### 11. 通俗化文案

全站使用老年人易懂的通俗语言，避免网购专业术语：

| 专业术语 | 通俗说法 |
|----------|----------|
| 搜索 | 找找 |
| 商品 | 东西 |
| 购物车 | 我选好的东西 |
| 结算 | 去付钱 |
| 代付 | 帮付 / 帮忙付 |
| 待代付 | 等着我付 |
| 已代付 | 已付过的 |
| 我的订单 | 我买的东西 |
| 下单 | 提交 |

## 如何运行

### 环境要求

- Node.js >= 16

### 安装依赖

```bash
npm install
```

### 配置 AI 和语音服务（可选）

在 `.env` 文件中填入你的 API 密钥：

```env
# DeepSeek AI（用于智能导购助手）
DEEPSEEK_API_KEY=your-deepseek-api-key-here

# 百度语音（用于语音识别 + 语音合成）
BAIDU_SPEECH_APP_ID=your-app-id
BAIDU_SPEECH_API_KEY=your-api-key
BAIDU_SPEECH_SECRET_KEY=your-secret-key
```

> - 如不配置 DeepSeek API Key，AI 导购助手功能将不可用，其余功能正常运行。
> - 如不配置百度语音，语音输入和语音播报功能将不可用，其余功能正常运行。
> - 语音唤起功能使用浏览器 Web Speech API，无需额外配置（Chrome/Edge 支持最佳）。

### 启动服务器

```bash
npm start
```

服务器默认运行在 `http://localhost:3000`

### 访问应用

- **电脑访问**：浏览器打开 `http://localhost:3000`
- **手机访问**：同一局域网下，手机浏览器打开 `http://[电脑IP]:3000`

## 项目亮点

1. **极简适老设计**：大字体、大按钮、暖色调、语义化中文文案，符合老年人使用习惯
2. **通俗化文案**：全站使用老年人易懂的语言，"找找"代替"搜索"、"东西"代替"商品"、"帮付"代替"代付"
3. **Emoji 图文匹配**：用 Emoji 替代复杂图片，直观易懂，降低认知负担
4. **智能推荐系统**：混合推荐算法（品类偏好 + 关键词匹配 + 协同过滤 + 老年适用），冷启动 + 个性化双模式
5. **亲情帮付**：创新性的家庭协作购物模式，子女通过绑定关系为父母远程帮付
6. **AI 智能导购**：集成 DeepSeek 大模型，支持全场景对话、意图识别、自动执行操作
7. **语音唤起**：后台持续监听"你好小伴"唤醒词，无需点击即可打开 AI 助手
8. **语音交互**：集成百度语音 SDK + 浏览器 Web Speech API，支持语音输入、语音播报、语音命令
9. **智能安全提醒**：自动检测药品和大额消费，保护老年人购物安全
10. **行为追踪学习**：自动学习用户偏好，越用越懂你
11. **轻量部署**：JSON 文件存储，无需数据库，开箱即用

## 已知限制与改进方向

| 限制 | 说明 | 改进方向 |
|------|------|----------|
| 密码明文存储 | 未进行加密处理 | 引入 bcrypt 加密 |
| 无身份验证机制 | 无 Session/Token | 实现 JWT Token 验证 |
| JSON 文件存储 | 不适合生产环境 | 引入 SQLite / MongoDB |
| 无前端单元测试 | 缺乏自动化测试 | 引入 Jest / Vitest |
| 无地址管理 | 订单无收货地址 | 增加地址管理模块 |
| 语音唤起兼容性 | Safari 不支持 Web Speech API | 已做降级处理，提示用户点击按钮 |
