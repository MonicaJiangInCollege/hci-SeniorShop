# 访谈摘录（匿名）

## P3（67 岁，长辈）

- **最安心**：「字大，橙色看着暖和」「说我要买牛奶它真的帮我放进去了」
- **最困惑**：第一次不知道「等着我付」要等多久
- **敢不敢自己付**：「不敢，怕点错。让儿子付我放心。」
- **帮付理解**：「懂了，就是我选好，他付钱。」

## P6（71 岁，长辈）

- **最安心**：「读给我听挺好，不用眯着眼看」
- **最困惑**：注册时手机号输错一次；语音要说清楚「纯牛奶」
- **敢不敢自己付**：「以前淘宝不敢按付款，这个不用我按。」
- **帮付理解**：「儿子手机上能看到，他给我付过我就看到了。」

## P5（28 岁，代理）— T3 失败

- 误将「去付钱」理解为立即扣款，未注意到 pending 状态
- **迭代启示**：需结算前语音确认 + 更明确 TTS「已经告诉子女了」

## P2（58 岁，代理）

- 「淘宝首页东西太多，这个只有四个大按钮，我知道点哪里。」
- T3 理解度 3 分：「等着我付」文案比「待付款」好懂，但仍想问「等多久」
